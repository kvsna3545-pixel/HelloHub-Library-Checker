Featherlua AST Engine

Safe · Medium · Aggressive · AST parsing · Local renaming · Output verification
WebAssembly AGPL-3.0
ข้อจำกัดภาษา: Featherlua รองรับ Luau เท่านั้น ไม่รองรับ Lua 5.1–5.4 หรือ LuaJIT หากต้องการแปลง Lua มาตรฐาน ต้องใช้ Engine ที่ตรงกับเวอร์ชัน Lua นั้นโดยเฉพาะ
หาก Engine ไม่แสดงในกรอบด้านบน

บางเบราว์เซอร์หรือการตั้งค่าความปลอดภัยอาจไม่อนุญาตให้แสดงเว็บไซต์ภายนอกใน iframe ให้เปิด Engine แยกแท็บแทน

เปิด Featherlua AST Engine

Workflow: AST → HelloHub Vault

  1. เปิด AST Engine แล้ววาง Luau Source Code
  2. เลือก Safe, Medium หรือ Aggressive และกด Compress
  3. คัดลอกผลลัพธ์จาก Engine
  4. กลับมาที่ Script Editor แล้ววางผลลัพธ์
  5. กด Save to Vault เพื่อจัดเก็บใน HelloHub
หมายเหตุ: การเชื่อมต่อระหว่าง AST Engine กับ Script Vault ยังเป็นแบบคัดลอก/วาง ไม่ได้ส่งผลลัพธ์ข้ามโดเมนโดยอัตโนมัติ และไม่ควรใส่ API keys, รหัสผ่าน หรือข้อมูลลับลงใน Source Code
